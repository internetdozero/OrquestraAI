# CLI: Granular Control for Idea Vault & Blackboard Notes

The `orquestra idea` (and alias `orquestra ideas`) CLI provides command-line control over OrquestraAI's **Idea Vault** and **Inter-Agent Blackboard Notes**.

It enables headless terminal environments, autonomous agents, and CI/CD pipelines to create, query, inspect, transition, and export tasks, ideas, and asynchronous collaboration notes without launching the desktop GUI.

---

## Architecture & Storage Model

Both the desktop application, the `orquestra-idea-vault` MCP server, and the CLI share the same SQLite database:
- **Default Database Location:** `~/.local/share/idea-vault/ideas.sqlite3`
- **Overrides:** Honors `IDEA_VAULT_DB_PATH` and `XDG_DATA_HOME` environment variables.
- **Concurrency & Locking:** SQLite configured with Write-Ahead Logging (`WAL`), `synchronous=NORMAL`, and a 5-second busy timeout. Multiple CLI instances, agents, and the GUI safely read and write concurrently without blocking.

### Core Entities

1. **Idea / Task (`IdeaItem`):**
   - Fields: `id`, `project`, `title`, `description`, `category`, `priority`, `tags`, `status`, `prompt`, `created_at`, `updated_at`, `completed_at`.
   - **Categories:** `feature` (default), `architecture`, `bug`, `ux`, `idea`.
   - **Priorities:** `critical`, `high`, `medium` (default), `low`.
   - **Statuses:** `open` (default), `in_progress`, `completed`, `archived`.
   - **Prompt:** Exact technical Builder dispatch prompt generated by the Orchestrator.
   - **Sorting:** Highest priority first (`critical` > `high` > `medium` > `low`), then newest `created_at DESC`, `id DESC`.

2. **Blackboard Note (`BlackboardNote`):**
   - Fields: `id`, `project`, `topic`, `sender`, `target`, `note`, `is_read`, `created_at`.
   - **Topic:** Lowercased tag identifying the message domain.
   - **Target:** Target agent or role (defaults to `all`).
   - **Sender:** Submitting agent or CLI operator (defaults to `agent` / `operator`).
   - **Sorting:** Chronological (`created_at ASC`, `id ASC`).

## Current State vs Granular Redesign

### What Exists Today
The existing implementation in `src-tauri/src/cli/native/ideas.rs` only supports 3 basic commands under the `orquestra ideas` root:
- `orquestra ideas add --project <p> --title <t> [...]`
- `orquestra ideas list [--project <p>] [--status <s>] [--limit <l>] [--offset <o>] [--json]`
- `orquestra ideas status <id> <status> [--json]`

**Limitations:**
- Does not recognize the canonical singular command `orquestra idea` (only plural `ideas`).
- Cannot inspect or get a single idea (`get`/`inspect`).
- Cannot update fields of an existing idea without resetting status or recreating (`update`).
- Cannot delete ideas (`delete`).
- Cannot search title, description, tags, or prompts (`search`).
- Cannot export markdown summaries (`export-md`).
- Cannot list distinct projects (`projects`).
- Cannot inspect velocity metrics (`metrics`).
- Completely lacks Blackboard Note subcommands (`note-post`, `note-list`, `note-get`, `note-read`, `note-clear`).

### The Granular Redesign
The redesigned CLI introduces comprehensive subcommands grouped under `orquestra idea` (with `orquestra ideas` alias retained for backward compatibility), providing full parity with the `orquestra-idea-vault` MCP and Rust backend capabilities.

```
orquestra idea
├── list              List ideas with multi-criteria filtering
├── get               Inspect full details and prompt of an idea
├── add               Record a new idea or task
├── update            Partially update fields of an idea
├── status            Transition idea lifecycle status
├── delete            Permanently delete an idea
├── search            Full-text search in titles, descriptions, tags, and prompts
├── projects          List all registered projects
├── export-md         Generate GitHub Markdown task board
├── metrics           Display productivity velocity metrics
├── note-post         Publish an inter-agent blackboard note
├── note-list         List blackboard notes
├── note-get          Inspect an individual note
├── note-read         Mark a blackboard note as read
└── note-clear        Purge handled blackboard notes
```

All commands support human-readable standard output by default, and structured JSON output via the `--json` switch.

## Command Reference: Ideas & Tasks

### 1. `list`
List ideas matching specified filters, sorted by priority and recency.

```bash
orquestra idea list [options]
```

- **Options:**
  - `--project <name>`: Filter by project name (e.g., `OrquestraAI`).
  - `--status <status>`: Filter by status: `open` (default if omitted), `in_progress`, `completed`, `archived`, or `all` (disables status filter).
  - `--category <cat>`: Filter by category (`feature`, `architecture`, `bug`, `ux`, `idea`).
  - `--priority <prio>`: Filter by priority (`critical`, `high`, `medium`, `low`).
  - `--limit <n>`: Maximum number of rows to return (default: 50, max: 2000).
  - `--offset <n>`: Number of rows to skip (default: 0).
  - `--json`: Output as JSON array of `IdeaItem`.

**Examples:**
```bash
# List all open ideas for OrquestraAI
orquestra idea list --project OrquestraAI

# List high and critical priority ideas across all statuses in JSON
orquestra idea list --status all --priority high --json
```

---

### 2. `get` (or `inspect`)
Inspect complete details of a single idea, including description, tags, and technical Builder dispatch prompt.

```bash
orquestra idea get <id> [--json]
```

- **Arguments:**
  - `<id>`: Integer ID of the idea.
- **Options:**
  - `--json`: Output full `IdeaItem` JSON object.

**Examples:**
```bash
orquestra idea get 42
orquestra idea get 42 --json
```

---

### 3. `add` (or `record`)
Record a new idea or task into the vault.

```bash
orquestra idea add --project <project> --title <title> [options]
```

- **Required Flags:**
  - `--project <project>`: Project name identifier.
  - `--title <title>`: Task title or short summary.
- **Optional Flags:**
  - `--description <text>`: Detailed task description.
  - `--category <cat>`: Category (`feature`, `architecture`, `bug`, `ux`, `idea`). Default: `feature`.
  - `--priority <prio>`: Priority (`critical`, `high`, `medium`, `low`). Default: `medium`.
  - `--tags <tags>`: Comma-separated or JSON array of tags (e.g. `cli,ideas`).
  - `--prompt <prompt>`: Technical Builder dispatch prompt in Markdown.
  - `--status <status>`: Initial status (`open`, `in_progress`, `completed`, `archived`). Default: `open`.
  - `--json`: Output created `IdeaItem` as JSON.

**Example:**
```bash
orquestra idea add \
  --project OrquestraAI \
  --title "CLI: orquestra idea granular control" \
  --category feature \
  --priority high \
  --tags "cli,ideas,idea-vault" \
  --description "Granular CLI control over ideas and blackboard notes"
```

---

### 4. `update`
Partially update fields of an existing idea without resetting unspecified fields.

```bash
orquestra idea update <id> [options]
```

- **Arguments:**
  - `<id>`: Integer ID of the idea.
- **Optional Flags:**
  - `--title <title>`: New title.
  - `--project <project>`: New project name.
  - `--description <text>`: New description.
  - `--category <cat>`: New category.
  - `--priority <prio>`: New priority.
  - `--tags <tags>`: New tags.
  - `--prompt <prompt>`: New technical Builder prompt.
  - `--status <status>`: New status.
  - `--json`: Output updated `IdeaItem` as JSON.

**Example:**
```bash
orquestra idea update 42 --priority critical --tags "cli,release-blocker"
```

---

### 5. `status`
Convenient shortcut to transition an idea's lifecycle status.

```bash
orquestra idea status <id> <status> [--json]
```

- **Arguments:**
  - `<id>`: Integer ID of the idea.
  - `<status>`: Target status (`open`, `in_progress`, `completed`, `archived`).
- **Behavior:**
  - Transitioning to `completed` stamps `completed_at = CURRENT_TIMESTAMP`.
  - Transitioning back to `open` or `in_progress` clears `completed_at = NULL`.
  - Transitioning to `archived` preserves existing `completed_at`.

**Example:**
```bash
orquestra idea status 42 in_progress
orquestra idea status 42 completed
```

---

### 6. `delete`
Permanently remove an idea from the vault.

```bash
orquestra idea delete <id> [--json]
```

- **Arguments:**
  - `<id>`: Integer ID of the idea.
- **Options:**
  - `--json`: Output confirmation object `{"id": 42, "deleted": true}`.

**Example:**
```bash
orquestra idea delete 42
```

---

### 7. `search`
Search ideas by substring match across `title`, `description`, `tags`, and `prompt`.

```bash
orquestra idea search <query> [options]
```

- **Arguments:**
  - `<query>`: Search query string (case-insensitive substring match).
- **Options:**
  - `--project <name>`: Restrict search to specified project.
  - `--limit <n>`: Maximum results (default: 50).
  - `--json`: Output matching ideas as JSON.

**Example:**
```bash
orquestra idea search "granular cli" --project OrquestraAI
```

---

### 8. `projects`
List all unique project identifiers currently registered in the Idea Vault.

```bash
orquestra idea projects [--json]
```

**Example:**
```bash
orquestra idea projects
```

---

### 9. `export-md`
Export active ideas (`open` and `in_progress`) for a project formatted as GitHub-style Markdown checklist.

```bash
orquestra idea export-md --project <project> [options]
```

- **Required Flags:**
  - `--project <project>`: Project to export.
- **Options:**
  - `--out <path>`: Write markdown directly to file instead of stdout.
  - `--json`: Output raw object with count and markdown string.

**Example:**
```bash
orquestra idea export-md --project OrquestraAI --out /tmp/ideas-board.md
```

---

### 10. `metrics`
Display developer velocity metrics, task completion counts, and heatmaps.

```bash
orquestra idea metrics [options]
```

- **Options:**
  - `--project <project>`: Filter metrics for specific project.
  - `--weeks <n>`: Number of weeks of historical data (default: 12).
  - `--json`: Output `ProductivityMetrics` JSON.

**Example:**
```bash
orquestra idea metrics --project OrquestraAI --weeks 4
```

## Command Reference: Blackboard Notes

Blackboard notes provide an asynchronous, multi-agent communication channel stored directly in SQLite. Agents and CLI users post notes, inspect unread messages, and clear completed directives.

### 1. `note-post`
Post a collaboration note on the blackboard.

```bash
orquestra idea note-post --project <project> --topic <topic> --note <text> [options]
```

- **Required Flags:**
  - `--project <project>`: Project namespace.
  - `--topic <topic>`: Topic identifier (automatically lowercased).
  - `--note <text>`: Message or handoff payload.
- **Optional Flags:**
  - `--sender <name>`: Posting agent or user identifier (default: `operator`).
  - `--target <target>`: Target agent or recipient (default: `all`).
  - `--json`: Output created note as JSON.

**Example:**
```bash
orquestra idea note-post \
  --project OrquestraAI \
  --topic "build-status" \
  --note "Artifact release compiled cleanly, ready for smoke test" \
  --sender "builder-1" \
  --target "orchestrator"
```

---

### 2. `note-list`
List blackboard notes matching topic or read status.

```bash
orquestra idea note-list [options]
```

- **Options:**
  - `--project <project>`: Filter by project.
  - `--topic <topic>`: Filter by lowercased topic.
  - `--unread-only`: Show only notes where `is_read = 0`.
  - `--limit <n>`: Maximum notes to return (default: 100).
  - `--offset <n>`: Offset for pagination.
  - `--json`: Output as JSON array of `BlackboardNote`.

**Example:**
```bash
orquestra idea note-list --project OrquestraAI --unread-only
```

---

### 3. `note-get`
Inspect an individual blackboard note by ID.

```bash
orquestra idea note-get <id> [--json]
```

---

### 4. `note-read`
Mark a blackboard note as read.

```bash
orquestra idea note-read <id> [--json]
```

**Example:**
```bash
orquestra idea note-read 15
```

---

### 5. `note-clear`
Purge handled blackboard notes for a given project.

```bash
orquestra idea note-clear --project <project> [options]
```

- **Required Flags:**
  - `--project <project>`: Project namespace.
- **Optional Flags:**
  - `--topic <topic>`: Restrict clearance to specific topic.
  - `--include-unread`: Delete all notes including unread ones (by default, only read notes are deleted).
  - `--json`: Output clearance summary.

**Example:**
```bash
# Clear all read notes for OrquestraAI
orquestra idea note-clear --project OrquestraAI
```

## Exit Codes & Output Conventions

- **`0`**: Success. Output rendered to standard output.
- **`1`**: Operation Error. Validation failure, non-existent record ID, or database query error. Error message printed to standard error.
- **`2`**: Usage Error. Missing required arguments, unknown flags, or malformed syntax. Usage summary printed to standard error.

### Pipe and Scripting Integration
With `--json`, any command output can be parsed directly with `jq` or Python:
```bash
# Get the active Builder prompt for Idea #42 and pipe to clipboard or runner
orquestra idea get 42 --json | jq -r '.prompt'

# List IDs of all open critical bugs
orquestra idea list --category bug --priority critical --status open --json | jq '.[].id'
```
